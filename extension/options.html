Headlines and prices come from the public cryptocurrency.cv API. No account, no key, no tracking.

The tab the popup opens on.

How often the background worker checks for new headlines and prices. The public API allows 120 anonymous requests per hour; every check uses two.

A notification fires for a newly published headline from a top-tier source or one the API scores as high impact. At most three per check.
